Independent Engine Architecture

Cleanly decoupled into a core parsing engine (engine.py) and a native UI shell (slre.py).

Built for Modularity and Distribution

The core parser handles HTML parsing, tag hierarchy, robust form submissions (GET and POST), image fetching, and link routing independently. This allows developers to embed the SLRE engine into any Python project or package it with PyInstaller.
