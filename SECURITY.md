# Security Policy

## Supported Versions

Supported versions depend on your Python Version.

| Version | Supported          |
| ------- | ------------------ |
| 3.10 or below   | ❌ |
|  3.11   | ✅ (Security fixes)             |
| 3.18  | :white_check_mark: |
| 3.16   | ✅               |

## Reporting a Vulnerability

You can report a vulnerability in our discussions.
