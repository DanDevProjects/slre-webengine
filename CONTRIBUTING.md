## How Can I Contribute?

### Reporting Bugs

Check the GitHub Issues page first to ensure the bug has not already been reported. 

If it is a new issue, submit a bug report including:
* A clear title and description of the problem.
* Steps to reproduce the behavior.
* Expected vs. actual results.
* Environment details (OS, language version, framework versions).

Note: Do not open a public issue for security vulnerabilities.

### Suggesting Enhancements

1. Check existing issues to ensure the enhancement has not been proposed yet.
2. Open a new issue outlining the problem and your proposed solution.
3. Explain the use case and how it benefits the project.

### Pull Requests

1. Fork the repository and create your branch from main.
2. Use a descriptive branch name (e.g., feature/login-auth or fix/jwt-expiration).
3. Add tests if your code introduces new logic.
4. Ensure the full test suite passes locally.
5. Update the documentation if your change alters public interfaces or behavior.
6. Open the PR against the main branch.
